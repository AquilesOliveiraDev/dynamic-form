# 🌐 DynamicForm Universal Specification (JSON Schema)

This directory contains the formal JSON Schema contract `dynamic-form.schema.json` that standardizes form structure and reactive dependencies for **any programming language and architecture** (Server-Driven UI - SDUI).

---

## 1. Backend Usage & Validation Examples

### 🐹 Go
Validate schemas generated by the backend using `github.com/santhosh-tekuri/jsonschema/v5`:
```go
package main

import (
	"encoding/json"
	"strings"
	"github.com/santhosh-tekuri/jsonschema/v5"
)

func ValidateFormSchema(schemaJSON []byte) error {
	compiler := jsonschema.NewCompiler()
	if err := compiler.AddResource("schema.json", strings.NewReader(dynamicFormSchemaContent)); err != nil {
		return err
	}
	schema, err := compiler.Compile("schema.json")
	if err != nil {
		return err
	}
	var v interface{}
	if err := json.Unmarshal(schemaJSON, &v); err != nil {
		return err
	}
	return schema.Validate(v)
}
```

### ☕ Java / Spring Boot
Validate using `networknt/json-schema-validator`:
```java
import com.networknt.schema.JsonSchema;
import com.networknt.schema.JsonSchemaFactory;
import com.networknt.schema.SpecVersion;
import com.networknt.schema.ValidationMessage;
import com.fasterxml.jackson.databind.JsonNode;
import com.fasterxml.jackson.databind.ObjectMapper;
import java.util.Set;

public class DynamicFormValidatorService {
    private final JsonSchema schema;

    public DynamicFormValidatorService() {
        JsonSchemaFactory factory = JsonSchemaFactory.getInstance(SpecVersion.VersionFlag.V7);
        this.schema = factory.getSchema(getClass().getResourceAsStream("/spec/dynamic-form.schema.json"));
    }

    public Set<ValidationMessage> validate(String json) throws Exception {
        JsonNode node = new ObjectMapper().readTree(json);
        return schema.validate(node);
    }
}
```

### 🎯 C# / .NET 8
Validate using `JsonSchema.Net`:
```csharp
using Json.Schema;
using System.Text.Json.Nodes;

var schema = JsonSchema.FromFile("spec/dynamic-form.schema.json");
var jsonNode = JsonNode.Parse(formJsonString);
var results = schema.Evaluate(jsonNode);

if (!results.IsValid) {
    foreach (var detail in results.Details) {
        Console.WriteLine(detail.Message);
    }
}
```

### 🐍 Python (FastAPI / Django)
Validate using `jsonschema` or Pydantic v2:
```python
import json
import jsonschema

with open("spec/dynamic-form.schema.json") as f:
    schema = json.load(f)

def validate_dynamic_form(payload: dict):
    jsonschema.validate(instance=payload, schema=schema)
```
